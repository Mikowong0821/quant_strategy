# 05｜回测与组合配权：分数怎么变成净值？

**发笔记用标题（可改）：**  
量化回测｜因子只负责排序，真正难的是把它变成持仓

---

**正文（可复制改写）**

因子分数不是策略，它只回答：

**同一天里，谁更值得排在前面？**

回测要继续回答：

```text
什么时候调仓？
买哪几只？
每只买多少？
手续费怎么扣？
每天净值怎么变？
```

这个 MVP 里，回测规则很克制：

- 初始现金归一为 1.0
- 默认月末口径调仓
- 调仓日按因子降序取 Top-K
- 先卖后买
- 单边手续费
- 现金不够时缩买入
- 每天用现金 + 持仓市值记录净值

Top-K 只解决“买哪几只”。

买多少由 `portfolio_weighting` 决定：

- `equal`：Top-K 等权，最透明的基线。
- `max_sharpe`：用这 K 只历史收益估 μ 和 Σ，再最大化夏普。
- `risk_parity`：用协方差 Σ 平衡风险贡献。

重点是：配权只发生在已经选出的 Top-K 内部。

也就是说：

```text
因子负责选股。
组合优化负责分资金。
回测负责现金、持仓、手续费和净值。
```

每次调仓还会留下 `rebalance_log`：日期、股票名单、权重、配权方式。  
这比只看一条净值曲线更重要，因为它能告诉你系统到底做了什么。

**本篇讲清的量化核心点：**  
再平衡、Top-K、交易成本、等权 / 最大夏普 / 风险平价，以及为什么选股和配权要分层。
