# 10｜缓存、落盘与路线图：能复现，才敢迭代

**发笔记用标题（可改）：**  
量化笔记｜为什么我要把中间结果也存进 `output`？

---

**正文**

`live/cache_io` 可选把行情、面板、IC 等写成 CSV：不是为了占磁盘，是为了 **对照**：「上周那版参数跑出来的 IC 均值是不是这一版」。

`persist_run_outputs` 打开后，PNG 和表格落在 `config` 指定的输出目录——适合直接当小红书配图或写公号的素材。

目录里 **`live` 下的信号、模拟盘** 目前是 **占位**：MVP 先把研究链路灯跑绿，再接「可执行指令 → 仿真成交 → 真实报单」。顺序反过来，排错成本通常是指数级。

**本篇讲清的量化核心点：**  
可复现性；**研究 / 仿真 / 实盘** 分阶段交付，而不是一锅炖。
