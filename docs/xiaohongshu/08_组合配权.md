# 08｜组合配权：K 只股票里，钱怎么分？

**发笔记用标题（可改）：**  
选股和配权是两件事：Top-K 之后，为什么还要夏普 / 风险平价？

---

**正文**

Top-K 只回答 **买哪几只**；组合层还要回答 **各买多少钱**。

本仓库在已选中的 K 只股票子集上支持三种（`portfolio_weighting`）：  
- **等权**：每只 1/K，最简单、最难被估计误差坑。  
- **最大夏普**：用这 K 只的历史日收益估 μ、Σ，再解优化——**注意**：这里的 μ 是 **配权用**，和绩效里事后算的「净值夏普」不是同一个对象。  
- **风险平价**：主要用 **Σ** 去平衡风险贡献；典型设定里对 **μ 的依赖更弱**，和你在机构里听到的「先稳结构再进攻」是同一类直觉。

样本不足或优化失败时，会 **回退等权**，并在 log 里留下标签——这是工程上的「别因为优化器挂了就静默错下去」。

**本篇讲清的量化核心点：**  
选股 alpha 与 **组合构建** 分层；μ、Σ 估计噪声如何影响权重集中度。
