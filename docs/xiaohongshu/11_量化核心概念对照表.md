# 11｜一张表串起「量化研究主链路」（复习 + 收藏）

**发笔记用标题（可改）：**  
从数据到下单之间，到底隔了几层？一张表说清楚

---

**正文（表格可复制到笔记里）**

| 层 | 在问什么 | 本仓库对应（概念） |
|---|---------|-------------------|
| 数据 | 行情与基本面是否对齐、无未来函数 | 长表 / 宽表、接入与对齐 |
| 因子 | 同一天谁比谁「更好」 | 因子面板、四列默认因子 |
| 检验 | 这列分数历史上有没有一点预测味 | 日截面 IC vs 前瞻收益 |
| 合成 | 多列因子怎么变成一条总得分 | z-score +（可选）IC 列权融合 |
| 选股 | 每期买哪几只 | Top-K、降序 |
| 配权 | K 只里各买多少钱 | 等权 / 夏普 / 风险平价 |
| 执行假设 | 何时调仓、成本、成交规则 | 月末 ME、手续费、收盘价等 |
| 评价 | 这条策略历史上长什么样 | 年化、波动、夏普、回撤、图 |

记住一句：**越往左，越像「科学」；越往右，越像「生意」**。MVP 先把左边到「评价」钉死，再往右接实盘。
