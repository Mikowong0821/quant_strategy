# 07｜一张表串起量化研究主链路

**发笔记用标题（可改）：**  
从数据到净值之间，到底隔了几层？一张表说清楚

---

**正文（可复制改写）**

这个 MVP 系列最后一篇，不讲新模块，做一次总复盘。

量化研究不是“有个因子就能交易”，中间至少隔着这些层：

| 层 | 在问什么 |
|---|---|
| 数据 | 行情、价格、财务是否对齐？ |
| 因子 | 同一天里，谁更值得排前面？ |
| IC | 这列分数历史上有没有预测味？ |
| 融合 | 多列因子怎么合成一条总得分？ |
| 选股 | 每期买哪几只？ |
| 配权 | K 只股票里钱怎么分？ |
| 回测 | 现金、持仓、手续费、净值怎么变？ |
| 绩效 | 年化、波动、夏普、回撤如何？ |
| 复现 | 这次结果以后还能不能查回来？ |

这里最容易混淆的是几组概念：

**因子不是策略。**  
因子只是一列分数；策略还要有选股、配权、调仓、成本和评价。

**IC 不是回测。**  
IC 看排序和未来收益的关系；回测看账户路径和净值。

**选股不是配权。**  
Top-K 决定买什么；`portfolio_weighting` 决定买多少。

**配权夏普不是绩效夏普。**  
前者是调仓时的优化目标；后者是回测后的成绩单。

**跑通不等于复现。**  
能跑只是程序没报错；能复现才说明结果能被重新检查。

所以这个 MVP 的核心不是“四个因子多厉害”，而是先固定一条主线：

```text
数据 → 因子 → IC → 融合 → Top-K → 配权 → 回测 → 绩效 → 落盘
```

先闭合，再加厚。

**本篇讲清的量化核心点：**  
量化研究是一条分层链路；每层只回答自己的问题，系统才不会乱。

---

**图文页脚本**

1. 封面：从数据到净值，隔了几层？  
2. 总链路：数据 → 因子 → IC → 融合 → 回测  
3. 数据 / 因子：先对齐，再打分  
4. IC / 融合：先体检，再合成总分  
5. Top-K / 配权：买什么和买多少分开  
6. 回测 / 绩效：账户路径和成绩单分开  
7. 复现：跑通不是终点，能回看才重要  
8. 总结：先闭合，再加厚
