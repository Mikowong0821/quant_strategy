# 03｜数据与因子面板：先把表对齐，再让因子说话

**发笔记用标题（可改）：**  
量化工程｜为什么我说第一步不是算因子，而是把表对齐？

---

**正文（可复制改写）**

很多回测不可信，不是因为公式多复杂，而是最开始的数据就没对齐。

在这个 MVP 里，数据先被整理成两种形态：

**长表**：一天、一只股票、一行。  
适合和财报、公告日、基本面字段拼接。

**宽表**：一天一行，每列一只股票。  
适合算收益、动量、波动率，也适合回测日循环。

然后 `panel_builder` 会把默认四列因子合成一张因子面板：

```text
date × symbol → MOMENTUM / VOLATILITY / PE / ROE
```

这里有几个小纪律：

- 动量：过去 N 日收益。
- 波动率：取负号，所以数值越大代表波动越低。
- PE：取负号，所以数值越大代表估值越低。
- ROE：数值越大代表盈利能力越强。

也就是说，四列最后都统一成：

```text
因子值越大，越优先进入 Top-K。
```

财务数据还要按 `ann_date` 向后对齐到交易日：今天调仓，只能用今天之前已经公告的数据。

量化研究第一步不是写出漂亮公式，而是先保证：

**价格、财务、因子、回测，用的是同一套日期和股票网格。**

**本篇讲清的量化核心点：**  
长表 / 宽表 / 因子面板；避免未来函数从 **数据对齐** 开始。

---

**图文页脚本**

1. 封面：第一步不是算因子，是把表对齐  
2. 长表：一天 × 一只股票 = 一行  
3. 宽表：一天一行，每列一只股票  
4. 为什么要两张表：长表拼财务，宽表算收益  
5. 因子面板：date × symbol → 四列因子  
6. 四列方向统一：数值越大越优先  
7. 财务数据：只用已公告信息，防未来函数  
8. 总结：先把表对齐，再让因子说话
