# 03｜数据层：长表、宽表，本质是「怎么对齐」

**发笔记用标题（可改）：**  
量化第一步不是算因子，是把行情变成「机器读得懂的两张表」

---

**正文**

数据层解决三件事：**从哪来、长什么样、和谁对齐**。

本仓库里：优先本地演示 CSV，其次内置池子拉 Tushare，再没有密钥就用合成数据——保证 **第一篇就能跑绿**，而不是卡在申请接口。

工程上你会反复遇到两种形态：  
- **长表**：一天、一只股票、一行——好和财报、公告按日期拼。  
- **宽表**：一天一行，每列一只股票——好算横截面收益、好喂给回测日循环。

量化里一半的「灵异净值」，来自 **对齐半拍、前视偏差**。把长宽转换和交易日历钉死，后面因子和 IC 才有意义。

**本篇讲清的量化核心点：**  
面板数据（panel）直觉；**避免未来函数**从数据schema开始。
