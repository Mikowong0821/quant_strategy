# 基准与超额收益：策略到底赢在哪里？

## 发布标题

量化回测别只看收益：还要看有没有跑赢基准

## 封面文案

策略赚钱了  
不代表策略有效

## 正文

今天给 Quant Strategy MVP 又补了一块：

```text
基准与超额收益分析
```

之前我们的回测已经能输出：

- 年化收益
- 年化波动
- 夏普比率
- 最大回撤
- 净值图
- 调仓日志
- 实验配置记录

但这里还有一个很容易被忽略的问题：

```text
策略赚的钱，
到底是策略自己赚的，
还是股票池整体涨出来的？
```

所以这次新增了：

```text
analysis/benchmark.py
```

先做一个最小但很有用的基准：

```text
股票池等权基准
```

意思是：

```text
不做因子选股，
每天把当前股票池里的股票等权持有，
得到一条 BENCH_EQUAL_WEIGHT 净值曲线。
```

然后每条策略都和它比较。

这样就能看：

```text
策略有没有真的跑赢“无脑等权持有股票池”。
```

这次新增的指标有三个重点：

```text
excess_ann_return
年化超额收益

tracking_error
主动收益的年化波动

information_ratio
每承担一单位主动风险，获得多少主动收益
```

简单说：

```text
超额收益：有没有跑赢基准
跟踪误差：跑赢/跑输的波动有多大
信息比率：跑赢基准这件事稳不稳
```

新增输出：

```text
output/excess_nav_compare.png
```

这张图比普通净值图更“照妖镜”。

因为普通净值上涨，可能只是股票池整体涨了。

但超额净值上涨，才说明策略相对基准在持续占优。

现在 `performance_summary.csv` 也会多出相对基准指标。

所以一次回测可以同时回答：

```text
策略绝对收益怎么样？
策略相对基准怎么样？
超额收益是否稳定？
融合策略有没有真的比股票池平均表现更好？
```

这一步不改变因子，不改变回测规则，也不改变组合配权。

它只是让我们看结果时少一点错觉。

量化研究里，一个很重要的习惯是：

```text
不要只问收益多少，
要问相对谁的收益。
```
