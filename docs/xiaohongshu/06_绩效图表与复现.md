# 06｜绩效、图表与复现：别只盯着一条净值线

**发笔记用标题（可改）：**  
量化回测｜净值曲线跑出来以后，我还会看这 5 件事

---

**正文（可复制改写）**

回测跑出净值，不代表研究结束。

一条曲线好不好，至少要拆开看：

- 年化收益：样本期涨幅折算成年口径。
- 年化波动：净值每天抖得有多厉害。
- 夏普比率：单位波动换来多少收益。
- 最大回撤：从历史高点跌到低点最痛的一段。
- 权重路径：这条曲线背后到底持有什么。

这个 MVP 里，`performance.summarize` 会从净值算：

```text
ann_return / ann_vol / sharpe / max_drawdown
```

作图层会输出三类图：

- `nav_compare`：单因子 / 融合 / 基准净值。
- `excess_nav_compare`：相对股票池等权基准的超额净值。
- `turnover_compare`：各策略逐期换手率。
- `ic_compare` / `ic_timeseries`：因子是否阶段性失效。
- `weights_*`：持仓是否集中、是否频繁切换。

我还会把中间结果落盘：

```text
prices_long.csv
prices_wide_close.csv
factor_panel.csv
ic_*.csv
run_meta.txt
run_config.json
performance_summary.csv
rebalance_logs/*.csv
excess_nav_compare.png
turnover_logs/*.csv
turnover_compare.png
```

这不是为了占磁盘，而是为了复现。

否则过两周看到一张图，你可能已经忘了当时的回测区间、因子面板、IC 序列、配置口径和调仓路径。

量化研究最怕“我记得当时好像是这样”。

真正可迭代的结果，应该能被重新打开、重新对照、重新解释。

**本篇讲清的量化核心点：**  
绩效指标是事后描述；图表用于排错和解释；落盘是复现的起点。

---

**图文页脚本**

1. 封面：别只看净值线  
2. 绩效四件套：收益、波动、夏普、回撤  
3. 净值图：单因子 vs 融合  
4. IC 图：看因子有没有阶段性失效  
5. 权重图：看仓位是否过度集中  
6. 缓存文件：行情、面板、IC、元数据  
7. 为什么落盘：让结果可以复现  
8. 总结：好回测 = 指标 + 图 + 可复查文件
