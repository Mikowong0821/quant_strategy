# 02｜入口与配置：`main.py` 是导演，`config` 是剧本

**发笔记用标题（可改）：**  
量化代码｜我把所有「能改的参数」塞进一个 `config`，原因就三个

---

**正文**

`main.py` 不做具体数学，它做 **编排**：按固定顺序调用数据、因子、IC、融合、回测、绩效、作图。好处是：新人只看一个入口，排错时也知道「死在哪一步」。

`config.py`（`Settings`）集中管：回测区间、股票池、`top_k`、手续费、调仓频率、IC 前瞻天数、融合开关、`portfolio_weighting`（等权 / 夏普 / 风险平价）、是否落盘等。

Token 这类敏感项，建议只放 **环境变量**，别把密钥写进要推送的仓库。

**本篇讲清的量化核心点：**  
「策略逻辑」和「工程参数」分层；可复现实验从 **配置可版本化** 开始。
