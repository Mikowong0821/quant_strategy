# 小红书稿：Quant Strategy MVP 系列

本目录存放**按模块拆分**的笔记正文，方便逐篇发布；口径与仓库 `main.py`、`config.py`、`docs/FLOW_AND_MODULES.md` 一致。长文深度版可看 [docs/articles](../articles) 下的系列稿，项目总览版见 [MVP_PROJECT_ARTICLE.md](../MVP_PROJECT_ARTICLE.md)。

## 拆分判断

结合当前代码，原来的 11 篇「按模块拆分」方向是对的：它能覆盖 `main.py` 里从数据到作图的完整执行顺序。但如果按小红书发布节奏看，11 篇会有点碎，尤其是「IC / 融合 / 回测 / 配权」之间强相关，读者容易只记住名词，忘了它们在主流程里的位置。

更合理的做法是：**发布时按 7 篇主线走，仓库里保留 11 个模块稿当素材库**。也就是说，`03` 到 `11` 不需要删，它们可以作为长图、补充卡片、评论区答疑或后续加餐。

## 发帖时可自行调整

- 小红书单篇不宜信息过载：可从每篇里摘 **3～5 条 bullet + 1 张图** 先发，评论区再链到下一篇。
- 话题标签每篇文末已给一版，可按账号调词频、删增。
- 配图：流程图可用 `docs/FLOW_AND_MODULES.md` 里 Mermaid 导出 PNG；净值 / IC 图用本仓库 `python main.py` 跑出的 `output/*.png`。
