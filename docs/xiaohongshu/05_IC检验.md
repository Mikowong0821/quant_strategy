# 05｜IC：因子「有没有一点预测味」的体检报告

**发笔记用标题（可改）：**  
别急着上仓位，先看 IC：它在量什么？

---

**正文**

IC（这里用 **日截面 Spearman**）干一件事：这一天，因子分数和未来一段 **前瞻收益** 的秩相关，高说明「当天相对更看好的，后来平均更涨一点」——当然只是统计平均，不是每只都对。

在本仓库里有一条很重要的 **分层**：  
- **单因子回测**：IC **不参与** 当天选股排序，也不进 K 只里的资金比例。它负责 **评价与记录**。  
- **融合路径**：IC 的 **滞后 + 滚动** 结果会进入 **列权**（多因子怎么合成一列），这是「IC 进决策」的最小切片，且只作用在 **合成得分** 上，不混进组合优化那层的 μ、Σ。

这样你不容易把「看起来相关的历史噪声」直接编译成极端仓位。

**本篇讲清的量化核心点：**  
评价（IC）与交易（调仓规则）为什么要拆开；**前瞻收益窗口**与 IC 定义绑在一起。
