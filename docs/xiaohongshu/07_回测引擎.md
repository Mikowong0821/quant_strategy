# 07｜回测引擎：用规则把「分数」翻译成「买卖与净值」

**发笔记用标题（可改）：**  
回测不是画图，是一套 **可执行的会计契约**

---

**正文**

回测回答：若我历史上按某条规则交易，现金和持仓怎么变、净值曲线长什么样。

本仓库默认：**月末再平衡**、因子 **降序取前 K**、**先卖后买**、**单边手续费**、现金不够就 **缩买入**。成交价简化在 **日频收盘价** 框架里（MVP 口径，后续可加滑点、涨跌停等）。

每一条回测都会留下 **`rebalance_log`**：每期选了哪 K 只、权重多少、配权方式标签——这是 **排错与写研报** 的底稿，不是可有可无的 log。

单因子四条线 + 融合一条线，用的是同一套规则，差异只来自 **选股用的那一列分数**。

**本篇讲清的量化核心点：**  
再平衡频率、成本、成交假设；**可审计的交易路径** 比一条净值曲线更重要。

---

**配图建议**

- 时间轴：调仓日竖线 + 净值曲线。  
- 从 `rebalance_log` 截一条「本期 top_k 股票代码 + 权重」打码示例。
