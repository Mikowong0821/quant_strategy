# 换手率与交易成本：收益不是白来的

## 发布标题

量化回测别只看收益，还要看换手率

## 封面文案

收益不是白来的  
高换手会吃掉利润

## 正文

今天给 Quant Strategy MVP 又补了一块：

```text
换手率与交易成本分析
```

之前我们已经能看：

- 策略净值
- 基准净值
- 超额收益
- 信息比率
- 调仓日志
- 绩效汇总

但还缺一个很接近实盘的问题：

```text
策略为了赚这些钱，
到底交易了多少？
```

所以这次新增：

```text
analysis/turnover.py
```

它从 `rebalance_log` 里读取每期目标持仓和权重，然后计算：

```text
turnover = sum(abs(本期权重 - 上期权重))
```

也就是：

```text
本次调仓的成交金额 / 组合净值
```

比如上一期：

```text
A 60%
B 40%
```

这一期：

```text
B 50%
C 50%
```

那么换手率是：

```text
A: 60% -> 0%
B: 40% -> 50%
C: 0%  -> 50%

turnover = 0.6 + 0.1 + 0.5 = 1.2
```

意思是这次调仓大约交易了组合净值的 120%。

然后再用：

```text
estimated_cost = turnover * commission_rate
```

估算交易成本压力。

这次 `performance_summary.csv` 会新增：

```text
avg_turnover
max_turnover
total_turnover
estimated_total_cost
n_turnover_periods
```

还会新增：

```text
output/turnover_logs/*.csv
output/turnover_compare.png
```

为什么这很重要？

因为两条策略收益差不多时，低换手那条通常更值得继续研究。

高换手策略不是一定不好，但它对手续费、滑点、冲击成本更敏感。

量化研究不能只问：

```text
收益高不高？
```

还要问：

```text
为了这些收益，交易成本压力有多大？
```

这一步不改变策略逻辑。

它只是让我们看结果时更接近真实交易。
